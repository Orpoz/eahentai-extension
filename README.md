# eahentai-extension

Mihon/Tachiyomi-compatible extension and extension store for **eahentai.com**, intended for use with
[Suwayomi-Server](https://github.com/Suwayomi/Suwayomi-Server).

> Status: **work in progress** — see [PROGRESS.md](PROGRESS.md) and [FINDINGS.md](FINDINGS.md).

## Task outline
1. Check whether an existing extension (Keiyoushi, yuzono/cursed-manga-repo, others) already supports eahentai.com.
2. If not, analyse the site (pages, URL patterns, APIs, image loading).
3. Build an extension against the Keiyoushi extension API, test it, and publish an extension store (`index.pb`) from this repository.
4. Document installation for Suwayomi.
